# AI Research Lab

完全初心者からAI研究者を目指すための、スマホ対応の学習・研究・ノート記録プラットフォーム。

## ページ
- `index.html`：学習ホーム
- `intro.html`：20ステップ入門
- `course.html`：14単元の体系コース
- `research.html`：研究計画ワーク・Markdown出力
- `notes.html`：Obsidian連携ガイド

## Obsidian
教材ノート：`obsidian/`
Windowsの片方向自動取り込み：[docs/OBSIDIAN_AUTO_SYNC.md](docs/OBSIDIAN_AUTO_SYNC.md)

## 公開
GitHub Pagesはmainブランチのrootを使用する前提。PRマージ後にデプロイを確認してください。

## 注意
- 進捗は各ブラウザ保存。端末間自動同期は未実装。
- PC側のタスクスケジューラ設定がなければObsidianの定期取り込みは起動しない。
- 公開GitHubへ顧客データ・秘密情報・個人メモをpushしないこと。
