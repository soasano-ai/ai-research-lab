# 研究者になるためのロードマップ

## Phase 0｜最初の4週間
- Python・数学・英語の現状確認
- 仮説、評価指標、比較実験を学ぶ
- 評価対象のコードは公開可能なものに限定

**合格条件**：10課題の予備実験を実施し、失敗例を説明できる。

## Phase 1｜1〜3か月
- Pythonの変数・関数・例外・テスト・CSV処理
- 平均、ばらつき、確率、相関と因果
- Git / GitHub / デバッグ / ドキュメント

**合格条件**：AI補助なしで簡単なPythonのデータ処理とテストを実装できる。

## Phase 2｜4〜6か月
- 機械学習、学習/推論、過学習
- TransformerとPyTorchの基礎
- 英語論文を1本再現

**合格条件**：モデル評価コードを自分で説明できる。

## Phase 3｜7〜12か月
- AI Coding Agentsの信頼性研究
- 比較条件・試行回数・指標の事前定義
- 公開可能な実験レポート作成

**合格条件**：第三者が手順を追って再実行できる。

## Phase 4｜13〜24か月
- 研究レポート2〜3本・外部レビュー
- オープンソースへの貢献
- 英語での技術説明

## Phase 5｜25〜36か月
- 最新の求人要件で研究・実装力を再確認
- Research Engineer / Fellowship 等への応募を検討
- 英語面接、ライブコーディング、研究設計を練習

期限より、各Phaseの合格条件を優先する。
