# Obsidian取り込み手順

この obsidian フォルダ内のMarkdownを、PCのObsidian Vault内の **AI_Research_Lab** フォルダへコピーしてください。
Obsidianでは `00_Start_Here.md` を開きます。Wikiリンク（[[01_Roadmap]]など）がつながります。

Web学習ツールから書き出した `.md` ノートも同じフォルダにコピーできます。
