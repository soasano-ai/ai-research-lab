# AI研究ラボ v3.2：質問・知識ライブラリ運用

## 初心者の学習導線
1. `intro.html` で入門、`course.html` で体系学習
2. 分からない言葉は `knowledge.html` で調べる
3. まだ理解できない点を `questions.html` に記録
4. 自分で調べた説明・参考URL・未解決/確認中/解決を管理
5. 質問ノートを .md で書き出し、Obsidianへ手動で取り込む

## 質問ノートの仕様
- 記録：質問、疑問が生まれた場面、答え、参考URL、状態、日時
- 検索と状態別フィルタ
- 編集・削除・JSONバックアップと復元
- Markdownエクスポート
- データ保存先：端末ブラウザのlocalStorage
- AIに自動送信したり、自動回答したりする機能は**まだない**

## Obsidian連携の区別
- 既存の `scripts/sync-obsidian.ps1`：公開教材（GitHub→Windows）の一方向自動取り込み
- 質問ノート：利用者が .md をエクスポートしてVaultに移す
- 完全自動同期や端末間同期：未実装、認証付きの設計が必要
- **質問データをPublic GitHubへ自動pushしない**。業務情報・個人情報を含む質問の公開に注意

## 次に検討すること
- 学習中の用語から質問フォームへ疑問文を引き継ぐ
- 学習トピックとの自動タグ付け
- クライアント側の練習問題拡充
- AI質問回答：秘密APIキーを公開しないため、認証・利用料・バックエンド設計が必要
- 安全な個人ノート同期方式の選定

- 再読込後の質問保存とJSONバックアップ復元
- Obsidian用Markdownの日本語と改行
- 知識ライブラリの検索・カテゴリ切替
- 各ページのリンクとバージョン表示
