# AI Research Lab v3 大枠設計

## 目的
AI完全初心者が、言葉を理解する段階から、コードの検証・定量評価・研究実績の公開まで到達できる学習システム。

## 4つの画面
1. 理解（`intro.html`）：20ステップ入門。
2. 学習（`course.html`）：14単元のテスト・記述練習。
3. 研究（`research.html`）：問い、仮説、比較条件、測定指標、限界。
4. 記録（`notes.html`）：Markdown書き出しとObsidian教材の片方向同期。

`index.html` を上記の入口となる学習ダッシュボードに変更。

## 今後の開発優先順位
- P1: 学習コース内の詳しい解説と多数の実技問題、スマホ実機テスト
- P2: 安全に隔離されたPython演習環境
- P3: 実験結果CSVの分析とグラフ表示
- P4: ログインとプライベートな端末間同期
- P5: 英語論文読解・公開研究ポートフォリオ

## セキュリティと制約
- Pagesは静的サイトであり、PCのローカルVaultを直接操作できない。
- 学習進捗は現在端末ごとのブラウザ保存。
- 機密・社内情報・個人ノートを公開GitHubへ送信しない。
- Obsidian自動同期はWindows上で、GitHubの公開教材だけを取り込む設計。
- Xやnoteの運用はプロジェクトの対象外。
